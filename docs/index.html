InstallationInstallation

First launchPremier lancement

The app isn't signed by Apple or Google (that costs money every year), so your system may ask for confirmation the first time.L'app n'est pas signée par Apple ou Google (c'est payant chaque année), votre système peut donc demander une confirmation au premier lancement.

macOS

Unzip, move G-System Editor to Applications, then right-click the app → Open → Open. If macOS says the app is damaged, run this once in Terminal:

Décompressez, glissez G-System Editor dans Applications, puis clic droit sur l'app → Ouvrir → Ouvrir. Si macOS indique que l'app est endommagée, lancez une fois dans le Terminal :

xattr -cr "/Applications/G-System Editor.app"
Linux

Make the AppImage executable, then run it:

Rendez l'AppImage exécutable, puis lancez-la :

chmod +x G-System.Editor-*.AppImage
./G-System.Editor-*.AppImage

If the G-System isn't detected, make sure your user can access USB MIDI devices (usually the audio group).

Si le G-System n'est pas détecté, vérifiez que votre utilisateur a accès aux périphériques MIDI USB (en général le groupe audio).

Android

Open the downloaded APK and allow installs from this source when Android asks. Connect the G-System's USB port to your phone with an OTG cable — the phone acts as the USB host — then tap Connect.

Ouvrez l'APK téléchargé et autorisez l'installation depuis cette source quand Android le demande. Reliez le port USB du G-System au téléphone avec un câble OTG — le téléphone fait office d'hôte USB — puis touchez Connect.
